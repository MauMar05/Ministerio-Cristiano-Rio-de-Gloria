# Ministerio Internacional Río de Gloria — Church Website

A website for Ministerio Internacional Río de Gloria in San Salvador, El Salvador. The site introduces the ministry, shares service schedules, highlights church activities, and helps visitors find the location and social media pages.

## Website Sections

- **Home:** Ministry name, welcome message, and navigation links.
- **Service Schedule:** Sunday services at 8:30 AM and 11:30 AM, plus Thursday service at 6:30 PM.
- **About the Ministry:** Introduction to the church and its pastors.
- **Events and Activities:** Links to pages for Sobrenatural, Tiempos de Poder y Milagros, Invasión Evangelística, and Jueves de Avivamiento.
- **Gallery:** Images from worship services and church activities.
- **Visit Us:** Address in Barrio San Miguelito, San Salvador, and a link to Google Maps directions.
- **Social Media:** Links to Instagram, TikTok, and YouTube search results related to the ministry.

## Built With

- HTML
- CSS
- JavaScript

## Project Structure

The main page references these project assets:

- `index.html` — main website page
- `css/styles.css` — visual styles
- `js/main.js` — JavaScript functionality
- `images/` — logos, church photos, event images, and gallery images
- Additional event pages: `domingos.html`, `poder.html`, `invasion.html`, and `avivamiento.html`

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/MauMar05/Ministerio-Cristiano-Rio-de-Gloria.git
   ```

2. Open the project folder.
3. Open `index.html` in a web browser.

Keep the referenced CSS, JavaScript, image assets, and event pages in their expected folders so the website displays correctly.

## Purpose

This project demonstrates a front-end website designed to present information for a local ministry and make practical details—such as service times, location, events, and social links—easy to find.
